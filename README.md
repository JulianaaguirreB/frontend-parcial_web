Frontend de bodegas y productos.

Requiere Node.js 24 y npm.
Abrir una terminal en esta carpeta y ejecutar: npm install
Cuando termine, ejecutar: npm start
Abrir http://localhost:4200
El backend debe estar funcionando en http://localhost:8080

Permite registrar bodegas con nombre y ubicacion y consultar los productos de cada bodega.
Los productos se obtienen del backend.

Para compilar, ejecutar: npm run build
